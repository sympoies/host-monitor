# AGENTS.md

This application owns portable Linux and macOS host collection, the read-only central API, and the browser UI. Infra repositories own host configuration, installed artifacts, systemd, and Tailscale exposure. Read DEVELOPMENT.md before editing. Never collect or expose environments, credentials, raw journal or unified-log messages, launchd job environments or arguments, provider transcripts, or container configuration. Do not add browser-controlled shell actions. Preserve accurate unknown/unavailable/stale states. Run npm run validate and browser acceptance before reporting deployment success. Use governed signed commits and managed worktrees; an empty repository's initial commit needs the explicit bootstrap authority required by the home policy.

History lives in the development log, `docs/devlog/` (conventions and month index in `docs/devlog/README.md`); there is no `CHANGELOG.md`, and none may be added. Every version bump adds a devlog release entry, and other non-trivial work adds an entry after the owning documents are current. Never put secrets, tokens, machine-local home paths, or collected host data in it.
